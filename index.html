1¿Qué son los números de Catalan?

Los números de Catalan son una lista de números que aparece una y otra vez cuando contamos formas de organizar cosas sin que se “rompa” una regla. Se llaman así por el matemático belga Eugène Catalan (siglo XIX).

Se escriben Cn, donde n es la posición (empezamos a contar desde 0):

n012345678
Cn112514421324291430
Idea clave: Cn responde preguntas como “¿de cuántas maneras puedo acomodar n pares de paréntesis correctamente?” o “¿de cuántas maneras puedo partir un polígono en triángulos?”. Problemas que parecen distintos… ¡dan exactamente los mismos números!

2La fórmula directa

Para calcular cualquier número de Catalan se usa:

Cn = 1n + 1 · (2n)!n! · n! = (2n)!(n + 1)! · n!

Recuerda: el factorial n! es multiplicar todos los números del 1 hasta n. Por ejemplo, 4! = 4·3·2·1 = 24 y por definición 0! = 1.

La parte (2n)!n!·n! es la combinación “2n en n”, que se escribe C(2n, n) o (2n n).

Ejemplo paso a paso: C3

n = 3 → 2n = 6 C₃ = 6! / (4! · 3!) = 720 / (24 · 6) = 720 / 144 = 5 ✅

Otro ejemplo: C4

n = 4 → 2n = 8 C₄ = 8! / (5! · 4!) = 40320 / (120 · 24) = 40320 / 2880 = 14 ✅
Truco para no hacer cuentas enormes: cancela antes de multiplicar. 8!/5! = 8·7·6 = 336, y luego 336 / 4! = 336 / 24 = 14.

3La fórmula recursiva (construir con los anteriores)

También podemos obtener cada número usando los que ya conocemos:

C0 = 1     y     Cn+1 = C0Cn + C1Cn−1 + … + CnC0

Es decir: multiplicas parejas que suman n en sus índices (uno sube, el otro baja) y sumas todo.

Ejemplo: C4

C₄ = C₀·C₃ + C₁·C₂ + C₂·C₁ + C₃·C₀ = 1·5 + 1·2 + 2·1 + 5·1 = 5 + 2 + 2 + 5 = 14 ✅
¿Por qué funciona? Piensa en paréntesis: toda expresión correcta empieza con “(”. Ese paréntesis se cierra en algún lugar. Lo que queda adentro es una expresión correcta más pequeña y lo que queda afuera (a la derecha) también. Si adentro hay k pares y afuera n−k, hay Ck·Cn−k formas. Sumando todas las opciones de k sale la fórmula.

4Aplicación 1: paréntesis bien balanceados

¿De cuántas formas se pueden escribir n pares de paréntesis de forma correcta? “Correcta” significa que nunca cierras un paréntesis que no abriste.

  • (()) ✅ correcto
  • ())( ❌ incorrecto: cierra antes de abrir

Con n = 3 hay exactamente 5 formas: ((())), (()()), (())(), ()(()), ()()().

5Aplicación 2: montañas (caminos de Dyck)

Dibuja una montaña con n subidas / y n bajadas \, sin bajar nunca del suelo. ¿Cuántas montañas distintas hay? ¡Cn!

Conexión: cada “(” es una subida y cada “)” es una bajada. “No cerrar lo que no abriste” es lo mismo que “no bajar del suelo”. Por eso dan el mismo número.

6Aplicación 3: triangular un polígono

Un polígono convexo con n + 2 lados se puede dividir en triángulos trazando diagonales que no se crucen. El número de formas es Cn.

Otras cosas que cuentan los números de Catalan

🌳 Árboles binarios

Formas distintas de un árbol binario con n nodos.

🤝 Saludos en una mesa

2n personas en una mesa redonda se dan la mano por parejas sin que los brazos se crucen.

✖️ Multiplicar en orden

Formas de poner paréntesis a n+1 factores: con a·b·c·d hay 5 → (ab)(cd), ((ab)c)d, (a(bc))d, a((bc)d), a(b(cd)).

🗺️ Caminos en cuadrícula

Caminos de esquina a esquina en una cuadrícula n×n que no cruzan la diagonal.

7¿Por qué funciona la fórmula? (explicación intuitiva)

Usemos los paréntesis (o montañas). Tenemos n “(” y n “)”, o sea, 2n símbolos.

  1. Todas las formas de acomodarlos, sin importar si están bien o mal: elegir en qué n de los 2n lugares van los “(”. Eso es C(2n, n).
  2. Las formas malas (que en algún momento “bajan del suelo”) resultan ser exactamente C(2n, n+1). Esto se demuestra con un truco llamado principio de reflexión: en el primer momento en que el camino baja del suelo, se “refleja” (se invierten) todos los pasos que siguen, y cada camino malo se convierte en uno con n+1 bajadas y n−1 subidas, de forma única.
  3. Las buenas = todas − malas.
Cn = C(2n, n) − C(2n, n+1)
Ejemplo con n = 3: Todas = C(6,3) = 20 Malas = C(6,4) = 15 Buenas = 20 − 15 = 5 ✅ (¡igual que antes!)

Si haces el álgebra de esa resta, se simplifica justo a 1n+1·C(2n, n). Así nace la fórmula del punto 2.

Aquí están los problemas típicos de programación con números de Catalan, del más sencillo al más “de concurso”. Cada uno tiene: el enunciado, la idea, el código en C++, su complejidad y un botón para ver qué imprimiría el programa.

Errores comunes (¡ojo!)

  • Usar int: se desborda en C20. Usa long long o unsigned long long.
  • Olvidar el caso base C[0] = 1: todo sale 0.
  • En la fórmula, dividir antes de multiplicar: c / (i+2) * ... da resultados incorrectos porque la división entera trunca. Primero multiplica, luego divide.
  • Confundir los índices de la suma: es C[k] * C[i-1-k] (los índices suman i−1).
  • Usar la versión recursiva para n grande: tarda muchísimo porque recalcula lo mismo una y otra vez.

10Practica (con respuestas)

Ejercicios para resolver en papel

1. Calcula C5 con la fórmula directa
C₅ = 10! / (6! · 5!) = (10·9·8·7) / 5! ← cancelando 6! = 5040 / 120 = 42
2. Calcula C5 con la recurrencia
C₅ = C₀C₄ + C₁C₃ + C₂C₂ + C₃C₁ + C₄C₀ = 14 + 5 + 4 + 5 + 14 = 42
3. ¿De cuántas formas se puede triangular un heptágono (7 lados)?
7 lados = n + 2 → n = 5 Respuesta: C₅ = 42 formas
4. ¿Cuántas montañas hay con 4 subidas y 4 bajadas?
n = 4 → C₄ = 14 montañas
5. ¿Cuál es el número que sigue: 1, 1, 2, 5, 14, 42, 132, ___?
Es C₇ = 14! / (8! · 7!) = 429

11Resumen para la clase

  • Secuencia: 1, 1, 2, 5, 14, 42, 132, 429… (empezando en C0).
  • Fórmula directa: Cn = (2n)! / ((n+1)! · n!).
  • Recurrencia: C0 = 1, Cn+1 = Σ Ck · Cn−k (k de 0 a n).
  • Otra forma: Cn = C(2n, n) − C(2n, n+1) (todas menos las malas).
  • Cuentan: paréntesis balanceados, montañas que no bajan del suelo, triangulaciones de un polígono de n+2 lados, árboles binarios, saludos sin cruzarse.
  • En C++: la forma recomendada es programación dinámica con C[i] += C[k] * C[i-1-k], O(n²); con módulo 10⁹+7 si n es grande.
  • La regla en común: “nunca cruzar el límite” (no cerrar antes de abrir, no bajar del suelo, no cruzar diagonales).
Frase para explicarlo en una línea: “Los números de Catalan cuentan de cuántas maneras se pueden ordenar cosas que se abren y se cierran sin que nada se cierre antes de abrirse.”
